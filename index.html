Método de Bisección

Método cerrado que divide el intervalo a la mitad. Garantiza convergencia si la función es continua y hay cambio de signo.

\[x_r = \frac{x_a + x_b}{2}\]

Falsa Posición

Mejora la bisección uniendo los puntos extremos con una línea recta para aproximar la raíz por interpolación lineal.

\[x_r = x_b - \frac{f(x_b)(x_a - x_b)}{f(x_a) - f(x_b)}\]

Punto Fijo

Transforma \(f(x)=0\) en \(x=g(x)\). El método converge si \(|g'(x)| < 1\) en el entorno de la raíz.

\[x_{i+1} = g(x_i)\]

Newton-Raphson

Utiliza la tangente de la función. Es el método más eficiente (convergencia cuadrática) pero requiere conocer la derivada.

\[x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}\]

Método de la Secante

Similar a Newton, pero sustituye la derivada por una aproximación basada en dos puntos anteriores.

\[x_{i+1} = x_i - \frac{f(x_i)(x_{i-1} - x_i)}{f(x_{i-1}) - f(x_i)}\]

Método de Müller

Utiliza una parábola (polinomio de segundo grado) que pasa por tres puntos. Permite encontrar raíces complejas.

\[x_3 = x_2 + \frac{-2c}{b \pm \sqrt{b^2 - 4ac}}\]

Método de Bairstow

Específico para polinomios. Encuentra factores cuadráticos del tipo \(x^2 - rx - s\) para hallar raíces reales y complejas.

\[r = r + \Delta r, \quad s = s + \Delta s\]

Regla de Horner

Algoritmo para evaluar polinomios de forma eficiente reduciendo el número de multiplicaciones. Usado también para Newton sobre polinomios.

\[b_i = a_i + b_{i+1}\,x\]

Newton para Sistemas

Extensión para resolver múltiples ecuaciones no lineales simultáneamente usando la matriz Jacobiana.

\[[J]\{\Delta x\} = -\{f\}\]

Método de Jacobi

Método iterativo para sistemas lineales \(A\mathbf{x}=\mathbf{b}\). En cada paso recalcula cada incógnita con los valores anteriores de las demás. Converge si la matriz es diagonalmente dominante.

\[ x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j \neq i} a_{ij}\, x_j^{(k)} \right) \]

Forma matricial: \(\mathbf{x}^{(k+1)} = D^{-1}\bigl(\mathbf{b} - (L+U)\mathbf{x}^{(k)}\bigr)\).

Método de Gauss-Seidel

Variante de Jacobi que usa los valores ya actualizados en la misma iteración. Suele converger más rápido bajo las mismas condiciones.

\[ x_i^{(k+1)} = \frac{1}{a_{ii}} \left( b_i - \sum_{j=1}^{i-1} a_{ij}\, x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij}\, x_j^{(k)} \right) \]

Forma matricial: \(\mathbf{x}^{(k+1)} = (D+L)^{-1}\bigl(\mathbf{b} - U\mathbf{x}^{(k)}\bigr)\).

Euler Simple

Método de un paso para EDOs de la forma \(y'=f(x,y)\). Avanza usando la pendiente al inicio del intervalo. Sencillo pero con error de truncamiento \(O(h)\).

\[y_{i+1} = y_i + h\,f(x_i,\,y_i)\]

A menor \(h\) mayor precisión, pero más pasos de cálculo.

Euler Modificado (Heun)

Mejora Euler promediando la pendiente al inicio y al final del paso (predictor-corrector). Error de truncamiento \(O(h^2)\).

\[y_{i+1} = y_i + \frac{h}{2}\bigl[f(x_i,y_i) + f(x_{i+1},\tilde{y}_{i+1})\bigr]\]

Predictor: \(\tilde{y}_{i+1} = y_i + h\,f(x_i,y_i)\).

Integración de Romberg

Combina la regla del trapecio compuesta con la extrapolación de Richardson para obtener resultados de alta precisión con pocos niveles.

\[R(i,j) = \frac{4^j\,R(i,j-1) - R(i-1,j-1)}{4^j - 1}\]

La diagonal \(R(n,n)\) es la mejor estimación. Converge muy rápido cuando \(f\) es suave.
